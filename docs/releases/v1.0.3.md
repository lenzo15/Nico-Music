这次更新可以把排好的歌单分享给别人，也为专注页带来了跟随音乐和封面变化的「环形声谱」。

### 分享与导入歌单
- 在「全部音乐」「我喜欢的」或自建歌单中，点击「＋」左侧的分享按钮，即可按完整列表顺序导出 `.nicomix`。只分享歌曲链接和曲名，不包含音频或本机文件路径。
- 双击或拖入 `.nicomix` 即可预览。可以新建歌单，也可以直接加入当前列表；已有歌曲不重复，新歌曲按文件顺序追加。取消不会写入，确认后也不会自动播放。
- Windows 资源管理器新增歌单文件专属图标。正常启动新版一次即可注册双击打开；不会覆盖已选的其他默认程序。

### 专注模式与插件
- 新增「环形声谱」：128 条光条根据实际播放的频谱向封面内外伸缩。光条按整张封面的平均颜色计算对比色，低音增强同色泛光；暂停和恢复时只淡出、淡入光条。改用透明画布直接绘制，修复部分缩放比例下的白框闪烁。
- 专注预设和音源插件支持热重载。修改当前预设的参数或样式，无需重启或中断播放；移除音源插件也会保留已存曲目和歌单关系。

### 界面与项目整理
- 导入音乐和播放队列去掉了多余的内层边框；删除歌单时直接显示目标名称，并明确提示歌曲仍保留在音乐库中。
- 源码按模块整理，界面脚本、样式和图标分别归档。插件安装目录不变。

**下载与升级：** Windows 10/11 x64 用户请下载 **`NicoMusic-v1.0.3-windows-x64.zip`**。v1.0.2 可在「设置 → 关于」中检查更新。应用内更新不会新增或装回本地没有的插件；若升级后未见「环形声谱」，从新版 ZIP 的 `NicoMusic/plugins/` 将 `wavehalo` 文件夹复制到程序旁的 `plugins/` 即可。已自行调参的用户请先备份修改过的插件文件。开发者可下载 `NicoMusic-v1.0.3-source.zip`。
