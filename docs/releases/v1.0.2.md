## v1.0.2 更新说明

### 音乐库与歌单
- 在自建歌单或「我喜欢的」点击「＋」，导入的歌曲会直接加入当前列表，导入完成后不再跳回音乐库。
- 批量操作支持拖动排序：拖动一首已勾选的歌曲可整组移动，拖到列表边缘会自动滚动，也可用上下方向键微调。音乐库、收藏和各歌单分别保存顺序，不打乱正在播放的队列。
- 导入音乐、从音乐库删除歌曲或从歌单移除歌曲后，可用 **Ctrl+Z** 撤销、**Ctrl+Y** 重做。

### 音源插件
- 随包的哔哩哔哩插件支持用一个个人空间合集或系列列表链接导入多首歌（每次最多 500 首）。插件会先显示曲目数和导入目标，确认后才写入；普通视频链接仍按单曲添加。
- 卸载网页音源插件并重启后，对应入口和网页曲目会隐藏，但原链接、收藏和歌单关系保留，装回插件后恢复。新版的应用内更新不会装回已移走的插件目录。

### Windows 桌面体验
- 播放器运行期间常驻系统托盘，恢复主窗口不会移除图标，退出时才清理。
- 歌单工具栏改用图标按钮，删除歌单采用应用内确认框；调整了标题字号、列表间距和对话框样式。

**下载与升级：** Windows 10/11 x64 用户请下载 `NicoMusic-v1.0.2-windows-x64.zip`。手动升级时请从托盘完全退出旧版，再解压并覆盖程序目录；不需要删除用户数据目录。开发者可下载 `NicoMusic-v1.0.2-source.zip`。
